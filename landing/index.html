Household

A home for your agents.
A home for your pets.

A harness for harnesses. Household wraps terminal agents like Claude Code and Codex, gives each its own sandbox, and lets you talk to it from the messenger you already use.

Get started

Give this prompt to your coding agent:

prompt.md
# Set up Household

Read https://agents-household.dev/llms.txt and help me set up Household on my machine.

No Docker. Your agent installs the rest and asks you only for a key and a Telegram bot.
